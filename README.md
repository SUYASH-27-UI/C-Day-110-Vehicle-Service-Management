# Vehicle Service Center Management System – C Day 110

## Description
A C-based application for managing vehicle service records using structures and file handling.

## Features
- Register new vehicle services
- View all service records
- Search services using service ID
- Update service status
- Display total service records
- Store records permanently in a text file

## Technologies
- C Programming
- Structures
- File Handling

## Files
- `service.c`
- `services.txt`

## How to Compile
```bash
gcc service.c -o service
```

## How to Run
```bash
./service
```

## Concepts Used
Structures, Arrays, File Handling, Searching, String Functions and Menu-driven Programming.

**Note:** This is an educational management project.
